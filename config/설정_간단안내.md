# 전자책 목차 설정 간단 안내

관리 파일은 `config/books.json`입니다. GitHub에서 파일을 편집한 뒤 **Commit changes**를 누르면 배포 후 반영됩니다.

## 현재 운영 방식

- 사이트 제목: `[AI 2027] 부록 챕터`
- `autoDiscover: false`
- 표시 PDF: `Sample1_머리말.PDF`, `Sample2_차례.PDF`, `Sample3_진정한빅뱅의시작.PDF`
- 초기 보기: 한 쪽 보기, 기기 방향에 맞춘 자동 맞춤

현재는 `books`에 적힌 PDF만 목차에 표시됩니다. PDF 파일만 업로드하면 자동으로 추가되지 않습니다.

## PDF를 추가하는 방법

1. 저장소에 PDF를 업로드합니다.
2. `books.json`의 `books` 배열에 항목을 추가합니다.
3. 원하는 위치에 항목을 놓아 목차 순서를 정합니다.
4. 배포 후 PDF가 열리고 목차 이름이 맞는지 확인합니다.

```json
{
  "file": "Sample4_새로운장.pdf",
  "title": "새로운 장"
}
```

- `file`: 저장소 안의 정확한 경로입니다. 대소문자와 확장자도 일치해야 합니다.
- `title`: 목차에 표시할 이름입니다. 생략하면 `titleRules` 또는 파일명을 사용합니다.
- `visible: false`: 목차에서 숨깁니다.

## 자동 검색을 사용할 때

`autoDiscover`를 `true`로 바꾸면 저장소의 PDF를 자동으로 찾습니다. `books`에 직접 적은 항목이 먼저 표시되고 나머지가 파일 경로 순서로 추가됩니다.

자동 검색은 공개 GitHub API를 사용합니다. 목차 순서를 정확히 관리하려면 현재처럼 `autoDiscover: false`를 유지하는 편이 좋습니다.

## 초기 화면 설정

```json
"readerDefaults": {
  "fit": "auto",
  "twoPage": false
}
```

- `fit: "auto"`: 모바일 세로는 페이지 맞춤, 모바일 가로는 너비 맞춤, PC는 페이지 맞춤
- `fit: "page"`: 페이지 전체 맞춤
- `fit: "width"`: 화면 너비 맞춤
- `twoPage: true`: 가능한 화면에서 펼친 두 쪽 보기로 시작

모바일 세로 화면은 `twoPage` 값과 관계없이 한 쪽 보기로 표시됩니다.

## 오류가 날 때

- JSON의 쉼표, 따옴표, 괄호를 확인합니다.
- `file` 경로가 실제 PDF와 정확히 일치하는지 확인합니다.
- 같은 PDF가 두 번 등록되지 않았는지 확인합니다.
- GitHub Pages 배포가 끝난 뒤 다시 새로고침합니다.

공개 저장소의 PDF는 목차에서 숨겨도 원본 주소로 접근할 수 있습니다. 외부 공개가 불가능한 자료는 업로드하지 마세요.
